# Downloaded Tools

This release intentionally omits workstation-specific downloaded paths and any proprietary Siemens runtime binaries.

Use this reference as a reminder of the intended extension points:

- external Openness snippet collections
- MCP server experiments
- local bridge helpers such as `scripts/configure-vscode-tia-mcp.ps1`

For a distributable installation, rely on the packaged source scripts first. Add any extra local tools only after verifying licensing and local version compatibility.
