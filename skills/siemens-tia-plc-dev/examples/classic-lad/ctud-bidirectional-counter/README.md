# CTUD Bidirectional Counter

Use this example when the same network needs up-count, down-count, reset, and preset-load behavior.

- current signal path -> `CTUD.CU`
- down branch -> `CTUD.CD`
- reset branch -> `CTUD.R`
- load branch -> `CTUD.LD`

Compile on a clone before reusing it in a live project.
